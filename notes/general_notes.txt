

Object-Oriented Programming (OOP)
Concept	                                Definition	                            Purpose	                                                Example
Encapsulation	                        Hiding data using private/protected	    Protects data and enforces controlled access	        private balance; in BankAccount
Abstraction	                            Hiding unnecessary details	            Simplifies usage by exposing only what's necessary	    Car::start() hides igniteEngine()
Inheritance	                            One class derives from another	        Code reuse and hierarchical relationships	            Dog inherits from Animal
Polymorphism	                        Same function behaves differently	    Flexibility and dynamic behavior	                    makeSound() in Animal overridden in Dog
